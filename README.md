# Restaurant Ordering System

A collaborative C++ desktop application developed to support restaurant ordering and kitchen operations. The system uses a client/server architecture and provides a graphical interface for managing the ordering workflow.

## Project Overview

This project was developed as a team-based university software project. The application was designed to simulate a restaurant ordering system, connecting the customer-facing ordering interface with the server-side functionality.

The project focuses on desktop application development, GUI design, client/server communication, and software testing using C++ and Qt.

## My Contribution

I was responsible for the **client side and the complete design and implementation of the graphical user interface (GUI)**.

My work included:

- Designing the application's interface and overall visual layout
- Implementing the client-side GUI using Qt and C++
- Creating the user-facing screens and interface components
- Connecting the interface to the client-side ordering workflow
- Focusing on usability and clear navigation throughout the application

## Features

- Restaurant ordering interface
- Client/server architecture
- Order management

- Graphical user interface built with Qt
- Automated testing
